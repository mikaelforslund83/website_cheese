# SnøVittra / Lost in Cheese — website draft

A local, responsive static website. Original supplied files remain in ../Grafiskt Material.

## Preview
From this directory run `python3 -m http.server 8080` and open http://localhost:8080.
No dependencies or build step required. Opening index.html directly also shows the design, but the YouTube player should be tested over HTTP.

## Structure
- index.html — hero, embedded trailer, awards, game features, community and footer
- css/styles.css — responsive visual styles
- js/main.js — footer year
- assets/images/ — copied production assets with web-friendly names
- docs/links.md — source links and verification notes

## Direction
Owlboy-inspired artwork-led hero, studio branding at top left, Steam CTA and trailer above the fold on typical desktop screens, recognition immediately below. Uses supplied purple/yellow branding. No Owlboy assets copied.

This is a local review draft, not deployed. YouTube is externally hosted and requires network access. The player uses privacy-enhanced embedding. All external destinations are real links; service availability and Discord invite validity remain controlled by their owners.
